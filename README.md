# ワードドロウ

単語をひき、名前をつくる、創作のための道具です。単一のHTMLファイルで動きます。

## 収録しているもの

| 項目 | 件数 |
|---|---|
| 単語 | 39カテゴリ・8,903語 |
| 図鑑 | 11,892件 |
| 神話 | 1,285項目（出典つき） |
| SCP財団 | 1,108語＋Tale 138件 |
| 名前の国・地域 | 44 |
| 名前の方向性 | 27種 |

## 三つの機能

**WORD DRAW** — 分野を選んで単語をひきます。和の言葉、四字熟語、SF、オノマトペ、SCP財団など39のカテゴリがあります。

**NAME MAKER** — 国・性別・年代・方向性を選んで名前をつくります。44か国の実在の名前のほか、星座・大アルカナ・二十八宿・ルーン・錬金術をモチーフにした造語も出せます。

**DEX（図鑑）** — 収録しているものをすべて一覧・検索できます。

## 使い方

ブラウザで開くだけです。インストールは要りません。

お気に入りに登録したものと設定は、お使いの端末に保存されます。他の人には見えません。

## 動作について

- 単一のHTMLファイルなので、ダウンロードして手元でも開けます
- iPhoneの「ファイル」アプリで直接開くと、プレビュー表示になりボタンが反応しません。ブラウザで開いてください

## ライセンス

収録している語の解説は独自に記述したものです。SCP財団の記事名は、クリエイティブ・コモンズ 表示-継承 3.0 ライセンスのもとで公開されている [SCP Foundation](https://scp-wiki.wikidot.com/) および [SCP財団日本支部](https://scp-jp.wikidot.com/) に基づいています。
